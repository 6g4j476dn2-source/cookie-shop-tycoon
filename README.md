# James's Cookie Shop Tycoon

Open `index.html` in a modern browser. No installation, build step, or server required. All gameplay works offline; optional Google Fonts fall back to system fonts.

Start with $100 and manage a cookie shop for 30 days. Each day, choose a batch size, price, and advertising budget. Cookies cost $0.50 to bake, advertising is paid upfront, and daily overhead is $5. Unsold cookies expire. Prices, advertising, daily forecasts, growing awareness, and a little randomness determine demand. You cannot spend more cash than you have.

Your game is saved in browser local storage when available. The run ends after day 30 or if you cannot afford overhead plus one cookie ($5.50). Use **Reset game** or **Start a new shop** to play again.
