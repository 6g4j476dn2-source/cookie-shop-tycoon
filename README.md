# James's Cookie Shop Tycoon

Open `index.html` in a modern browser. No installation, build step, or server required.

Start with $100 and run your shop for 30 days. Set a quantity and selling price for each variety: chocolate chip costs $0.50 (suggested $2.00), double chocolate costs $0.75 (suggested $2.75), and oatmeal raisin costs $0.40 (suggested $1.75). Enter zero to skip a variety. Ingredients, advertising, and $5 daily overhead are paid upfront; spending cannot exceed cash. Unsold cookies expire.

Varieties share the audience. Popularity, prices, advertising, forecast, awareness, and randomness determine sales. Daily results break down each variety. Customer animations reflect total sales.

Progress saves locally when available, including original saved games. The game ends after day 30 or when cash is below $5.40, overhead plus the cheapest cookie. Reset starts a new shop.
